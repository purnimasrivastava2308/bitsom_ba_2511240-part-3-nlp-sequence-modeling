# Part 3: NLP and Sequence Modeling
Project structure for part 3 of NLP sequence modeling.

## Contents

- `notebook.ipynb`: analysis and experiments
- `requirements.txt`: Python dependencies
- `results/`: output artifacts
  - `model_evaluation.csv`: evaluation results
  - `sample_predictions.txt`: example predictions

## Customer Support Ticket Sentiment Classification

**Dataset**: `customer_support_text_classification.csv`

### Tasks Completed
- **Task 1**: Dataset understanding (3 classes: positive, negative, neutral)
- **Task 2**: Text cleaning and preprocessing
- **Task 3**: TF-IDF Vectorization + Tokenizer + Padding
- **Task 4**: Baseline Model (Logistic Regression + TF-IDF)
- **Task 5**: LSTM Sequence Model
- **Task 6**: Reflection on RNNs, LSTMs, Attention & Transformers

**Best Model**: LSTM Sequence Model (better at understanding context)
